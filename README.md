# ピュアナ 予約・売上管理システム

| ファイル | 役割 |
|---|---|
| `index.html` | お客様用の予約フォーム（概算金額の自動計算つき） |
| `partner.html` | 提携先・協力業者用の売上報告フォーム（提携コードで受付） |
| `assets/config.js` | GASのURL・店名・電話番号の設定 |
| `gas/Code.gs` | スプレッドシートに貼り付けるプログラム（保存・自動返信・通知・毎月レポート） |

データはGoogleドライブの「ピュアナ 予約・売上管理」スプレッドシートに集まります。

## 1. GAS（自動返信とデータ保存）を設定する

1. スプレッドシート「ピュアナ 予約・売上管理」を開く
2. メニューの「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身をすべて消し、`gas/Code.gs` の中身を貼り付けて保存（Ctrl+S）
4. 上の関数の選択欄で `setup` を選んで「実行」→ Googleの許可画面が出たら、ご自身で内容を確認して許可する
   - 「このアプリは確認されていません」と出た場合は「詳細」→「（安全でないページ）に移動」で進めます（自分で作ったプログラムのため表示されます）
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. 「デプロイ」を押し、表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピー

## 2. 予約フォームにURLを入れる

`assets/config.js` の `GAS_URL: ''` の `''` の中に、コピーしたURLを貼り付けます。電話番号を載せる場合は `PHONE` にも入れます。

## 3. GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作る（例：`pyuana-booking`、Public）
2. このフォルダの中身（`index.html`、`partner.html`、`assets` フォルダ）をアップロード
   - `gas` と `tools` フォルダはアップロードしなくて大丈夫です
3. リポジトリの「Settings」→「Pages」→ Branch を `main` / `(root)` にして保存
4. 数分後に `https://（ユーザー名）.github.io/pyuana-booking/` で公開されます

## 4. 毎日の使い方

- 新しい予約が入ると、お客様に確認メール、あなたに通知メールが届きます。
- 「予約データ」タブの **ステータス** を「日程調整中 → 日程確定 → 作業完了」と変えていきます。
- 作業が終わったら **確定作業日** と **確定金額** を入れてください（黄色の列）。レポートの売上はこの金額で集計します。
- 毎月1日の朝8時ごろ、前月の売上・分析レポートが「レポート ○年○月」タブに作られ、メールでも届きます。
- スプレッドシート上部の「ピュアナ管理」メニューから、今月分のレポートをいつでも作れます。

## 5. 提携先を追加する

「設定」タブの E〜G列に、提携先名・提携コード・連絡先メールを追加します。提携コードは推測されにくい文字列にし、提携先にだけ `partner.html` のURLと一緒に伝えてください。記入例の行は削除してください。

## 料金を変えるとき

`assets/booking.js` と `gas/Code.gs` の両方にある `PRICES` を同じ値に書き換えます。GASは書き換えたあと「デプロイ」→「デプロイを管理」→ 編集 →「新バージョン」で更新してください。

## 経路（どこから来た予約か）を記録する

本部の共通仕様（`Claude Code用プロンプト_予約フォームと数字の連携.md` の A-2）に合わせて、次の値をURLから自動で読み、予約と一緒に送ります。お客様に入力してもらう項目ではありません。

| URLに付ける値 | 意味 | 例 |
|---|---|---|
| `ref` | 紹介コード（紹介コード欄にも自動で入ります） | `?ref=TANAKA01` |
| `utm_source` | どこから来たか | `instagram`、`meta`、`google`、`flyer`、`portal` |
| `utm_medium` | 広告の種類 | `sns`、`ads`、`qr` |
| `utm_campaign` | 広告・チラシの名前 | `2026oct` |

- 値は英数字・`_`・`-` だけに整え、40文字までにします（日本語や記号は消えます）。
- 一度リンクから来たお客様は、90日間はその経路が記録されます。
- 店コードは `assets/config.js` の `STORE_CODE`（今は `pyuana`）です。
- 「予約データ」の最後の4列（**店コード／経路／広告コード／紹介あり**）に記録されます。紹介コード本体は「紹介コード」列にだけ残り、「紹介あり」列は 有/無 だけです。
- 経路は `utm_source` → 紹介コードあり（`referral`）→ ほかのサイトから（`web`）→ 直接（`direct`）の順で決まります。
- 毎月のレポートに「経路別の成績（予約受付・作業完了・売上・1件あたり）」が入ります。

リンクの例：
- Instagramのプロフィール：`…/pyuana-booking/?utm_source=instagram&utm_medium=sns`
- チラシのQRコード：`…/pyuana-booking/?utm_source=flyer&utm_medium=qr&utm_campaign=2026oct`
- 紹介カード：`…/pyuana-booking/?ref=紹介コード`
